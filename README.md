# BharatBites - Manual QA Testing Project

BharatBites is a portfolio simulation of end-to-end manual QA testing for an online food ordering web application.

## QA Artifacts
- 44 Requirements
- 49 Test Scenarios
- 67 Detailed Test Cases
- 67 Simulated Executions
- 6 Defect Reports
- Requirements Traceability Matrix (RTM)
- Test Summary Report

## Traceability Coverage
- Requirements covered in RTM: 44/44
- Test scenarios covered in RTM: 49/49
- Test cases mapped in RTM: 67/67

## Execution Summary
| Metric | Result |
|---|---:|
| Total | 67 |

## Project Flow
Requirements -> Test Plan -> Scenarios -> Test Cases -> Execution -> Defects -> Retesting/Regression -> RTM -> Summary

## Portfolio Disclosure
This project is a learning/portfolio simulation. Execution outcomes and defects are illustrative unless accompanied by actual application evidence.
